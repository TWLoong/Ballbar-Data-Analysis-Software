# 球杆仪数据处理软件

## 一、项目简介

  本软件是一款基于MATLAB App Designer开发的球杆仪数据处理工具，用于对千分表改装球杆仪采集的半径数据进行处理与分析。  
  导入上半圆、下半圆两个独立的 Excel 数据文件，进行数据筛选、圆度分析、谐波分析，并计算圆度误差、X/Y 轴反向间隙等指标。

- 开发环境：MATLAB R2022b
- 程序文件：BallbarAnalysis.m
- 界面语言：中文

## 二、主要功能

1. **数据导入**
   - 分别导入上半圆、下半圆两个独立的 Excel 文件（表格格式需与文件夹中的两个Excel相同）。

2. **数据筛选**
   - 由于千分表改装的测量仪器过长，且机床行程有限，无法一次完成整圆的数据采集，故分两次采集，每次采集半个圆，再在程序中做数据拼接
   - 需指定上半圆、下半圆的有效数据行范围（剔除启动/停止阶段的无效采集点）。
   - 筛选后更新数据。

4. **圆度分析**
   - 绘制 直角坐标系：角度—偏差曲线。
   - 绘制 极坐标系：闭合的极坐标轨迹。
   - 自动计算 圆度误差（基于最小二乘圆拟合）。
   - 自动计算 X 轴反向间隙、Y 轴反向间隙。

5. **谐波分析**
   - 对圆度偏差进行 FFT 分析，提取前 10 阶谐波。
   - 绘制各阶谐波波形（直角坐标系）。
   - 绘制各阶谐波占比柱状图。

6. **分析结果输出**
   - 点击“分析结果”按钮，集中显示圆度误差、X/Y 轴反向间隙以及谐波组成。
